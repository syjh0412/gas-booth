# 기체 실험 부스

중학교 1학년 과학 「기체의 성질」 단원의 정성 실험(기체의 압력, 보일 법칙, 샤를 법칙)을 부스 형태로 운영하기 위한 웹앱입니다.

## 할 수 있는 일

- **실험 고르기**: 32가지 실험 중 준비할 수 있는 것만 선택합니다. 선택은 기기에 저장되고, 링크로 공유할 수 있습니다.
- **슬라이드 보기**: 고른 실험만 순서대로 보여 줍니다. 실험마다 시작 → 준비 → 방법 → 예상 → 입자 → 정리 6장입니다. "이 부스만 보기"로 부스 태블릿에 한 실험만 띄울 수 있습니다.
- **입자 모형**: 부피, 온도, 입자 수를 바꾸며 입자의 움직임과 벽 충돌 횟수를 볼 수 있습니다.
- **활동지 인쇄**: 고른 실험만, A4 한 장에 1·2·3·4·6칸 중에서 골라 인쇄합니다. 교사용 예시 답을 표시할 수 있습니다.

## 성취기준 (2022 개정 교육과정)

- [9과06-01] 압력의 의미를 알고, 기체의 압력을 입자의 운동으로 설명할 수 있다.
- [9과06-02] 기체의 압력과 부피 관계를 실험 결과로부터 알아내고, 이를 입자 모형으로 해석할 수 있다.
- [9과06-03] 기체의 온도와 부피 관계를 실험 결과로부터 알아내고, 이를 입자 모형으로 해석할 수 있다.

보너스 미션은 성취기준 밖의 원리가 섞인 도전 과제입니다.

## 파일

- `index.html`, `style.css`, `app.js`: 화면과 동작
- `data.js`: 실험 내용, 그림, 활동지 문항 (자동 생성)

설치 없이 `index.html`을 열면 동작합니다. 인쇄할 때는 브라우저 인쇄 설정에서 용지 A4, 여백 없음, 배경 그래픽 켜기를 권합니다.

## 안전

실험 전에 반드시 예비 실험을 하고, 안전 약속을 학생과 함께 확인하세요.
